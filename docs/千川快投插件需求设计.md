# 千川快投插件需求设计

## 1. 文档信息

- 产品名称：千川快投
- 当前版本：MVP 原型 V0.1
- 更新时间：2026-08-10
- 原型位置：`prototypes/千川快投插件-demo/index.html`
- 原型来源：复用 AI 伴播项目 `live-console` 的直播中控台宿主页面、右侧浮标和抽屉结构，插件业务内容已替换为千川快投。

## 2. 业务背景

抖音直播间的自然推荐流量有限。短视频团队会围绕直播商品生产高关联短视频，再通过巨量千川购买短视频流量，引导用户进入正在直播的直播间。

公司存在较多缺少千川投放经验的新员工。直播过程中，他们很难同时判断素材表现、直播承接能力和追投时机，也难以正确配置千川计划。因此，需要提供一款浏览器插件，将算法判断转化为简单、可直接执行的追投建议。

核心价值是：系统负责判断“当前应该投什么”并填入建议参数，员工只需要确认追投方式、预算和目标后创建计划。

## 3. 产品目标

### 3.1 业务目标

- 在直播过程中及时放大高潜短视频素材，为直播间补充有效流量。
- 降低新人执行追投的学习成本和误操作风险。
- 建立“算法建议 -> 用户采纳 -> 计划创建 -> 投放效果”的可追踪链路。
- 为后续优化推荐算法和追投参数提供数据依据。

### 3.2 MVP 产品目标

- 在直播中控页面提供始终可见的“千川快投”入口。
- 使用三个业务 Tab：建议追投、待汰换、可召回；Tab 不展示数量。
- 用户可按“放量追投 / 控成本追投”分别选择建议素材、批量设置参数并创建计划。
- 用户可在看板内批量淘汰待汰换素材、批量召回历史素材；追投设置通过标题栏图标进入。

## 4. 产品边界

### 4.1 本期包含

- 算法追投建议列表。
- 素材、商品主图、素材标签和关键数据展示。
- 待汰换素材和可召回素材的看板内批量操作。
- 追投方式、优化目标和参数设置。
- 创建千川计划及过程状态反馈。
- 追投模版管理。
- 防重复提交和建议处理后的状态更新。

### 4.2 本期不包含

- 在插件内管理完整素材池。
- 在插件内编辑千川未开放的其他底层投放参数。
- 展示千川账户内并非由插件创建的全部计划。
- 自动执行所有算法建议；本期必须由用户确认创建。
- 素材标签规则和追投算法规则的最终配置，规则由业务后续补充。

## 5. 核心概念

### 5.1 素材与商品关联

短视频素材必须关联带货商品。系统根据本场直播商品筛选可投素材，避免推荐与当前直播商品无关的视频。

### 5.2 素材标签

- 放量：数据表现突出，适合扩大预算。
- 稳投：表现稳定，适合持续投放。
- 新素材：尚缺少有效投放样本，需要小预算测试。
- 待汰换：表现不佳，等待淘汰或替换；正常情况下不进入追投建议。

具体打标与迁移规则待业务补充。

### 5.3 素材生命周期

- 在池：当前可参与素材筛选和投放。
- 已淘汰：因素材表现或业务判断退出素材池，通常不再推荐。
- 可召回：因商品下架、过季等外部原因暂时退出；商品重新上架后可召回并恢复历史数据。

“停用”不作为独立生命周期状态。

### 5.4 追投方式与参数

素材标签用于描述素材当前状态，追投方式用于决定本次计划如何执行，两者是独立概念。

追投方式分为：

- 放量追投：用户输入调控预算和调控时长。
- 控成本追投：用户先选择优化目标，再填写该目标对应的参数。

控成本追投支持两个优化目标：

- 综合 ROI：以直播间综合投入产出比为优化目标，让更多人在直播间产生成交金额。综合 ROI = 净成交金额 / 综合成本。用户需要填写调控日预算、综合 ROI 目标。
- 直播间成交：以直播间成交成本为优化目标，触达更多支付且成交意愿度高的用户。成交成本 = 消耗 / 成交数，其中成交数为直播间内下单并支付成功的订单数。用户需要填写调控日预算、我的出价；我的出价单位为“元/成交”。

## 6. 信息架构

```text
千川快投
├── 建议追投
│   ├── 建议放量追投 / 批量创建
│   └── 建议控成本追投 / 批量创建
├── 待汰换
│   └── 待汰换素材 / 批量淘汰
├── 可召回
│   └── 可召回素材 / 批量召回
└── 标题栏追投设置图标
    ├── 千川广告主账号
    └── 追投模版管理
```

追投记录在本版本不展示。追投设置包含当前千川广告主账号和追投模版管理，通过看板标题栏右侧设置图标进入；追投模版仅管理本插件的快捷追投默认参数。

## 7. 页面与交互

### 7.1 右侧浮标

- 展示文案：千川快投。
- 点击后打开右侧插件抽屉。
- 插件打开后可点击右上角收起按钮收起，点击设置图标进入追投设置，再次点击返回建议追投。
- 看板顶部只展示“千川快投”和直播状态，不展示账号名称。
- 打开插件时默认进入“建议追投”。

### 7.2 Tab 1：建议追投

建议追投页不展示算法推荐状态、手动刷新入口、建议生成时间、更新时间或“建议 X 分钟内处理”等时间信息。列表只保留当前仍然成立的推荐计划，已撤回或失效的计划直接从列表移除。

建议追投页不展示素材库概览，以“放量追投 / 控成本追投”页内切换展示当前建议。两个方式的选择、全选、已选数量与批量创建相互独立，不混合创建。

#### 建议卡片

每条建议至少包含：

- 建议 ID。
- 素材封面和素材 ID，素材 ID 前展示标签：放量、稳投或新素材。
- 关联商品主图，不展示商品名称和商品 ID。
- 商品主图右侧单行展示四项关键决策数据。
- 卡片底部展示素材上传时间。

建议卡片不展示推荐理由。

推荐计划固定展示四项数据：近 7 日消耗、点击率、成交订单、ROI。

卡片不展示“优先追投”“建议追投”“首轮测试”等推荐级别文案，也不单独设置卡片头部。素材通常没有稳定名称，因此不展示素材名称；素材标签以短标签形式展示在素材 ID 前。

素材 ID 展示为“素材ID：***9671”，右侧保留复制图标，点击后复制完整素材 ID。若素材当日已经通过千川投放，素材 ID 行最右侧展示“今日已投{次数}次，消耗{金额}元”；未发生当日投放时不展示该提示，用于提醒操作人员避免重复追投。

卡片不展示选择框。用户单击整张卡片选中，再次单击取消选中；选中后卡片背景、边框及四个数据块同步变色。键盘操作支持使用 Enter 或空格切换选中状态。

#### 创建入口约束

- 推荐卡片不展示单条“创建计划”按钮。
- 每个建议追投区块只支持从本区块底部的批量操作栏发起创建。
- 用户只选择一条计划时，也通过“批量创建计划”入口完成创建。

#### 批量创建计划

1. 用户可以在放量或控成本区块内单击卡片逐条选择，也可以只对当前区块点击“全选”；再次单击已选卡片可取消选择。
2. 当前方式的操作栏固定在看板底部，实时展示“全选 / 取消全选”、已选计划数量和“批量创建计划”；未选择计划时不可点击，滚动素材列表时操作栏不移动。
3. 用户点击“批量创建计划”后，系统在浏览器窗口中央打开批量弹窗。
4. 弹窗以较大尺寸展示当前追投类型下的已选素材封面和商品主图，不展示商品名称、素材 ID、复制入口、已选数量提示、模版选择标题或手动创建说明；批量创建两条及以上素材时，弹窗顶部保留“批量填入计划”，可将一个同类型已有模版填入所有素材。每条计划的追投模版默认留空，用户可选择同类型的已有追投模版，或选择“不使用已有模版，手动创建”。
5. 选择已有追投模版后，按模版参数创建计划，不允许在本次创建中修改模版参数，也不重复展示模版参数摘要。
6. 未选择已有追投模版时，用户可在独立的浅蓝色“追投计划设置”区块内直接配置对应参数；放量区块固定为放量追投，控成本区块固定为控成本追投，均不展示追投方式选择。
7. 选择手动创建后，模版选择框后方展示并默认勾选“创建为新模版”；用户可取消勾选，不保存本次参数。追投模版全程无需填写名称，系统根据配置自动生成名称，包含已有模版、新建模版及编辑后的模版：放量为“放量{预算}元_{时长}小时”，控成本 ROI 为“控成本日{日预算}元_ROI{目标}”，控成本成交为“控成本日{日预算}元_出价{出价}元/成交”。
8. 放量追投展示调控预算、调控时长；控成本追投先选择“综合 ROI / 直播间成交”，再展示调控日预算、综合 ROI 目标或我的出价。控成本追投的两个参数输入项以两列等宽布局填满整行。
9. 用户确认后，系统一次提交多个创建任务，并防止重复点击。
10. 全部创建成功后，已创建计划从当前推荐列表移除；追投任务仅在后端留存，本版本看板不展示追投记录。
11. 若部分计划创建失败，失败计划保留在当前推荐列表并展示具体失败原因。

#### 可读性要求

- 插件面向直播过程中的快速操作，正文、数据和按钮字号应高于宿主页面的小号辅助文字。
- 素材 ID 使用灰色、常规字重和 11px 有效显示字号，仅展示脱敏后的末四位；复制图标始终复制完整 ID。四项数据相对其他主要操作文字使用较小字号，但必须在常见桌面分辨率下清晰可辨。
- 四项数据必须位于商品主图右侧并保持单行排列。
- 建议列表超出可视区域时仅列表区域纵向滚动，底部固定操作栏始终可见。

#### 当前推荐与去重

- 列表只展示算法当前仍在推荐的计划；算法撤回后立即从列表移除。
- 推荐时间、更新时间、推荐理由和处理时限均不在插件内展示。
- 同一建议提交时使用幂等键，避免网络重试产生重复计划。
- 一个建议成功创建计划后，不再出现在待处理列表。
- 批量创建时，每个推荐计划使用独立幂等键，避免部分重试导致重复计划。

### 7.3 Tab 2：待汰换

- 直接在看板内展示当前待汰换素材，不再通过弹窗处理。
- 卡片复用建议追投的选择与展示样式，展示素材封面、标签、素材 ID、商品主图、近 7 日消耗、点击率、成交订单、ROI 和上传时间。
- 用户可单击卡片选中或取消选中，也可点击底部“全选 / 取消全选”。
- 固定底部操作栏展示已选数量与“批量淘汰”按钮；点击后需在确认弹窗二次确认，确认淘汰后素材从当前列表移除。

### 7.4 Tab 3：可召回

- 直接在看板内展示可召回素材，不再使用召回弹窗。
- 只展示与当前直播小黄车上架商品相关的历史素材。
- 可召回素材已从千川移除，仅保留在公司服务器。卡片展示素材封面、素材名称、关联商品主图及历史消耗、点击率、成交订单、ROI；不展示千川素材 ID、复制入口或素材分层标签。可召回页素材封面使用更紧凑的尺寸。
- 固定底部操作栏支持单击选择、全选和“批量召回”；点击后需在确认弹窗二次确认，确认召回后素材从当前列表移除并回到素材库。

### 7.5 追投设置

追投设置页顶部展示当前千川广告主名称和广告主 ID；其下展示“千川素材库自动筛选素材”开关。开启后系统自动将素材分层为稳投、放量、新素材、待汰换，并将低效素材移出素材库；关闭后系统不再自动移除素材。下方为“追投模版”管理区域，不设置重复的二级标签。页面支持新建、编辑、删除放量追投或控成本追投的默认参数。控成本追投可配置优化目标、预算、ROI 目标或出价。新建和编辑模版均复用批量创建计划中的“追投计划设置”样式和交互，包括浅蓝色配置区、追投方式分段按钮、优化目标分段按钮及参数输入框。模版名称固定由系统按参数生成：放量“放量{预算}元_{时长}小时”、控成本 ROI“控成本日{日预算}元_ROI{目标}”、控成本成交“控成本日{日预算}元_出价{出价}元/成交”。

## 8. 状态设计

### 8.1 建议状态

- 待处理：可创建计划。
- 创建中：已提交，等待千川返回。
- 已采纳：计划创建成功，不再展示在待处理列表。
- 已失效：超过建议有效期。
- 创建失败：保留建议，允许重试。

### 8.2 创建任务状态

- 投放中。
- 已结束。

追投请求提交到任务 ID 返回之前，创建中和创建失败状态由批量创建流程承接。本版本不提供追投记录页，任务与状态仅用于后端数据留存和后续版本查询。

## 9. 数据关联

每次快捷投放需要记录以下主链路：

```text
直播间ID
  -> 建议ID
  -> 商品ID
  -> 素材ID
  -> 追投方式 / 优化目标 / 参数快照
  -> 追投任务ID
  -> 千川账户ID
  -> 千川计划ID
```

追投参数必须记录版本快照，避免后续修改后无法还原历史计划配置。

## 10. 接口能力建议

### 10.1 获取追投建议

输入：直播间 ID、千川账户 ID。

输出：当前推荐计划列表、素材和商品摘要、关键指标、建议的默认追投参数。

### 10.2 创建计划

输入：一个或多个建议 ID、素材 ID、商品 ID、追投方式、优化目标、预算、时长、目标值或出价、千川账户 ID，以及各计划独立的幂等键。

输出：各追投请求的任务 ID、任务状态、千川计划 ID、计划名称、失败原因和计划详情链接。

## 11. 异常与风险控制

- 千川未登录或授权过期：禁止创建，提示重新授权。
- 素材已淘汰、不可用或审核失败：建议失效，不允许投放。
- 商品已下架或不在本场直播：建议失效。
- 预算、时长、综合 ROI 目标或出价为空或小于等于 0：禁止创建并定位到对应素材。
- 账户余额不足：创建前拦截并提示。
- 计划创建超时：查询创建任务状态，不能直接再次提交。
- 数据回流延迟：使用“暂无数据”状态，避免将延迟数据误认为 0。

## 12. 核心产品指标

- 建议曝光数。
- 建议查看率。
- 建议采纳率。
- 从收到建议到创建计划的耗时。
- 计划创建成功率。
- 重复创建拦截次数。
- 不同素材标签的采纳率和投放效果。
- 不同投放产品、追投方式和优化目标的任务数、调控消耗、成交订单和 ROI。
- 建议采纳计划与非建议计划的效果差异。

## 13. MVP 验收标准

- 插件打开后仅展示“建议追投”“待汰换”“可召回”三个无数量 Tab；标题栏右侧设置图标用于打开追投设置，追投记录在本版本隐藏。
- 建议列表只展示当前推荐计划，不展示推荐时间、处理时限或推荐理由。
- 建议追投页不展示算法推荐状态和手动刷新入口。
- 建议追投页不展示素材库概览，使用“放量追投 / 控成本追投”切换展示当前建议；两个方式的选择、全选及批量创建操作相互独立。
- 建议列表不展示“优先追投”“建议追投”“首轮测试”等推荐级别文案。
- 放量、稳投、新素材标签展示在素材 ID 前；素材 ID 使用灰色、常规字重和 11px 有效显示字号，ID 后提供复制图标。
- 建议列表能展示素材、商品主图，以及位于商品主图右侧的单行四项数据；卡片底部展示素材上传时间。
- 点击素材封面可打开素材播放预览，点击商品主图可在浏览器中央查看大图。
- 素材卡片不展示选择框，支持单击整卡选中、再次单击取消，选中后卡片和数据块变色。
- 推荐卡片不展示单条“创建计划”按钮。
- 当前追投方式固定底部展示全选、已选数量和批量创建计划，方式间不混合创建；滚动素材列表时操作栏不移动。
- 支持逐条选择、按当前方式全选和批量创建计划。
- 放量区块的批量弹窗仅可选择放量追投模版，手动创建固定为放量追投且不展示方式选择；控成本区块仅可选择控成本追投模版，手动创建固定为控成本追投且不展示方式选择。
- 批量弹窗支持优先选择已有追投模版；选择后按模版创建计划，不重复展示模版参数摘要。
- 批量创建两条及以上素材时，弹窗顶部保留“批量填入计划”，支持选择一个已有追投模版并“填入全部”，一次套用到所有素材。
- 追投模版默认不选择；选择“不使用已有模版，手动创建”后可设置参数，且选择框后“创建为新模版”默认勾选。模版名称由系统根据配置自动生成，用户可取消保存。
- 放量追投支持填写调控预算和调控时长。
- 控成本追投支持选择“综合 ROI / 直播间成交”，并按目标展示对应字段。
- 综合 ROI 支持填写调控日预算、综合 ROI 目标。
- 直播间成交支持填写调控日预算、我的出价，出价单位为“元/成交”。
- 创建过程中按钮不可重复点击。
- 创建成功后建议被移除；任务数据在后端留存，本版本不展示追投记录。
- 待汰换与可召回均为独立 Tab，不通过素材选择弹窗操作；两页均支持单击选择、全选和底部固定批量操作栏，执行批量淘汰或批量召回前必须二次确认。可召回素材不展示千川素材 ID 与分层标签，仅展示素材名称和历史数据。
- 追投设置页展示千川广告主名称和广告主 ID；其中的追投模版支持新建、编辑、删除，且名称遵循系统命名规则。模版卡片仅展示类型标签、系统命名和创建时间，不展示参数摘要或更新时间；编辑和删除使用图标按钮，删除前必须二次确认。
- 追投设置页支持“千川素材库自动筛选素材”开关；开启时自动分层并移出低效素材，关闭后不自动移除素材。
- 追投设置页中，广告主账号以低干扰的信息条展示；追投模版以紧凑管理卡片展示，使用放量/控成本类型色条和标签辅助扫读，编辑与删除为轻量操作。
- 插件收起和重新打开正常，不影响宿主直播中控页面操作。
