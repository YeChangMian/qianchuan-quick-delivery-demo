# 千川快投

## 产品功能

- 管理千川素材：根据素材投放数据，支持汰换低效素材和召回历史素材。
- 提供素材投放建议：推荐适合放量或控成本追投的素材，支持一键批量追投。

## 使用场景

直播带货期间，运营人员可在直播中控台中快速选择推荐短视频并创建千川追投计划，提升直播间引流效率。
