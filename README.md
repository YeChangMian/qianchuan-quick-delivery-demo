# 千川快投插件 Demo

## 说明

本 Demo 从 AI 伴播项目的直播中控台插件原型复制并改造，保留了抖音直播中控台宿主页面、右侧浮标和抽屉式看板结构。

插件业务已替换为：

- 建议追投：以“放量追投 / 控成本追投”切换展示，当前方式内单击卡片选择推荐计划并批量创建。放量与控成本只可使用各自类型的模版，手动创建时也固定当前方式。
- 待汰换：在独立 Tab 内批量选择低效素材，二次确认后淘汰。
- 可召回：在独立 Tab 内展示公司服务器保存的历史素材，使用素材名称与历史数据代替千川素材 ID、分层标签；批量选择后需二次确认召回。
- 追投设置：通过看板标题栏右侧图标进入，展示千川广告主名称、广告主 ID 和“千川素材库自动筛选素材”开关；页面同时管理放量追投和控成本追投的常用追投模版。

## 文件

- `index.html`：抖音直播中控台宿主页面和插件挂载点。
- `qianchuan-plugin.css`：千川快投插件样式。
- `qianchuan-plugin.js`：三个业务 Tab、设置入口、模版管理、计划创建及素材淘汰/召回交互。
- `assets/`：从原 Demo 复制的宿主页面与商品示例图片。

## 查看方式

直接用浏览器打开 `index.html` 即可。页面加载后插件默认展开，也可以点击页面右侧“千川快投”浮标重新打开。

## 可演示路径

1. 在“建议追投”中切换“放量追投 / 控成本追投”，单击素材卡片选中，再次单击取消选中。
2. 使用当前方式的“全选”或逐条选择需要追投的计划，然后点击看板底部固定的“批量创建计划”。
3. 在浏览器窗口中央的弹窗中，为每条素材选择当前追投类型可用的已有模版；选择多条素材时，可在顶部使用“批量填入计划”一次套用。
4. 选择“不使用已有模版，手动创建”后，放量区只填写预算和时长；控成本区只填写优化目标及相应参数。“创建为新模版”默认勾选。
5. 点击“确认创建 N 个计划”，创建成功后素材从当前建议区块移除。
6. 切换到“待汰换”，多选或全选素材后点击“批量淘汰”，并在弹窗中确认。
7. 切换到“可召回”，查看素材名称与历史数据，多选或全选关联历史素材后点击“批量召回”，并在弹窗中确认。
8. 点击标题栏右侧设置图标，查看千川广告主账号并管理追投模版；再次点击返回建议追投。

## 原型说明

- 素材、建议、模板、计划和投放数据均为演示数据。
- 算法建议规则、素材标签规则和正式追投参数范围等待业务补充。
- 建议卡片不展示推荐级别文案和素材名称，素材标签位于灰色素材 ID 前；素材 ID 完整展示，空间不足时自然换行；卡片底部展示素材上传时间。
- 素材 ID 后提供复制图标；素材封面可点击播放预览，商品主图可点击放大。
- 手动创建的追投模版无需命名，系统自动按参数命名，例如 `放量1000元_2小时`、`控成本日500元_ROI2.8`、`控成本日500元_出价35元/成交`。
- 批量创建弹窗只展示较大尺寸的视频封面和商品主图，不展示素材 ID、商品名称或复制入口。
- 弹窗不展示已选数量提示、模版选择标题和手动创建说明，直接进入素材与配置内容。
- 追投参数区不展示消耗方式、ROI 或成交成本等辅助说明文本；未选择模版时下拉框保持空白。
- 已选择模版时不重复展示参数摘要；多素材批量创建支持已有追投模版一键填入全部。
- 手动创建时，参数以独立浅蓝色“追投计划设置”区块展示，和模版选择区分开；其追投方式由当前建议区块固定，不再出现方式选择。
- 追投模版卡片仅展示类型、系统命名和创建时间；编辑、删除使用图标按钮，删除前需在确认弹窗中再次确认。
- 本版本不展示追投记录；计划任务数据仅作为演示和后续接入的数据留存。
- 三个业务 Tab 均不展示数量。
- 对应产品需求文档：`../../docs/千川快投插件需求设计.md`。
